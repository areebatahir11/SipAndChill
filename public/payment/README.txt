Payment logos shown on the "Take Orders" payment picker (transparent PNGs, no background).

In use:
  jazzcash.png          JazzCash symbol
  easypaisa.png         Easypaisa "e" symbol (black + green) - used on light backgrounds
  easypaisa-light.png   the same with the black part reversed to white - used on dark backgrounds

Kept for other screens (full logo with the name):
  jazzcash-full.png, easypaisa-full.png

Bank transfer shows a bank icon (no file needed).
To change a logo, replace the file with a square transparent PNG of the same name (about 256 x 256 px).
If a file is missing, a plain phone icon is shown instead.
